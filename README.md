# Кухня внутри ПК

Мультик-учебник о том, как устроен компьютер: процессор, оперативная память, накопители, видеокарта, материнская плата, BIOS, разгон и сборка ПК под задачу.

Компьютер показан как кухня ресторана: процессор — повар, оперативка — его рабочий стол, накопитель — кладовка, видеокарта — художник. В каждой из 12 серий — анимированные кадры, блок «Запомни», подробности «Взрослым словами» и вопросы для самопроверки.
